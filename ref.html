Hosting Technologies & Deployment [POWERED BY BLAST]
[TECHNOLOGY] Static GitHub Pages + Dynamic BLAST Gateway Proxy

Deploy the frontend onto GitHub Pages for zero-cost static hosting. All interactive form actions, messages, and crypto proofs dynamically communicate with the secure BLAST Gateway on Render:

# Architecture pipeline:
GitHub Pages (Frontend) >> BLAST Gateway (Render Queue) >> Supabase DB

# In GitHub Repo Settings:
Settings > Pages > Build and deployment: Deploy from a branch (main / root)
[SECURITY VERIFIED] Direct Supabase credentials are never exposed in GitHub Pages frontend code.
[DEPLOYMENT] Automated Cloud Web Service on Render

Deploy RayzHub and BLAST Gateway with continuous deployment directly from your private GitHub repository:

Build Command: pip install -r requirements.txt
Start Command: uvicorn main:app --host 0.0.0.0 --port $PORT

Environment Variables:
BLAST_URL=https://your-blast-gateway.onrender.com
BLAST_KEY=your_cluster_security_token
[LOCAL NODE] Independent Standalone Daemon

Execute locally with loopback auto-discovery on 127.0.0.1:

# RayzHub Main Service (Port 8000):
python main.py

# Standalone Receiver Service (Port 8001):
python receive/main.py

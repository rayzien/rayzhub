# Background Images

Add your custom background images (`.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`, `.avif`, `.svg`, `.bmp`) into this folder.

- **Custom Images**: RayzHub will automatically detect and cycle through all images placed in this folder.
- **Empty Folder Fallback**: If no images are present in this folder, RayzHub will automatically fall back to the preloaded background images (from https://rayzien.github.io/rayzhub/).
